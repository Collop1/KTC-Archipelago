# The in-game Archipelago menu

The mod has its own Archipelago client built in, so you don't need to run a separate client program. Press **F2**
in game to open or close the menu. New to the mod? Start with the
[setup guide](../../apworld/kingdom_two_crowns/docs/setup_en.md).

## Tabs

| Tab | What it's for |
| --- | --- |
| **Connect** | Server address, slot name and password, connect and disconnect, auto-connect and DeathLink |
| **Items** | What you've unlocked so far (castle upgrades, technology, islands, bombs, statues, hermits, mounts, powers, coin sacks), gems the Greed have stolen, and every item you've received |
| **Checks** | Your progress towards the next milestone checks (island ones for the island you're on), checks left on your current island, and every check you haven't done yet, each with a Hint button |
| **Hints** | Your hint points, hint requests for items or locations, and every hint for your slot |
| **Chat** | Everything happening in the multiworld (items found, chat, server messages), plus a chat box for messages and commands like `!hint` and `!remaining` |
| **Debug** | Tools for trying things out: give yourself any item or trap, see what the game is doing, or send a check by hand if one didn't go through |
| **Settings** | Menu size and see-through amount, the key that opens the menu, and where and how long notifications show |

To type in a box, click it, type, and press Enter. While a box has focus your monarch stays put, so your keys don't
move them around.

**About the Debug tab:** items and traps you give yourself there are only for testing. They exist only on your
computer and are gone when you close the game. Sending a check by hand is real, though: it goes to the server like
any other check, so only use it for a check you really did that didn't go through.

## Notifications

A feed in the corner of the screen shows items you send and receive, traps that hit you, and connection news, even
with the menu closed. You can move it to another corner, change how long messages stay and how big they are in the
**Settings** tab.

## Good to know

- **Playing offline:** checks you make while you're disconnected are saved and sent as soon as you reconnect.
- **Wrong campaign:** if the campaign you have loaded isn't the one your seed is for, the menu says so, and nothing
  is sent or received until you load the right one.
- **Other mods:** Kingdom Enhanced uses F1, F3 and F4, so don't move the menu to one of those if you use it too.
- **Where things are saved:** your connection details and your progress for each seed live in
  `BepInEx/config/APKingdom2Crown/` in the game folder. There's nothing in there you need to edit.

Something not working? See the troubleshooting section of the
[setup guide](../../apworld/kingdom_two_crowns/docs/setup_en.md#troubleshooting).
